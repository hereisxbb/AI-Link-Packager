# AI Link Packager v0.1.0

First public release.

AI Link Packager is a Windows desktop tool for packaging Adobe Illustrator files together with their linked assets.

## Features

- Batch package Illustrator files
- Automatically collect linked assets
- Relink packaged assets
- Preserve original AI files
- Custom output folder names
- Packaging reports
- Portable Windows version
- Installer version

## Requirements

- Windows 10 / 11
- Adobe Illustrator installed

## Recommended Download

AI Link Packager Portable

No installation required.
